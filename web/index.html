🌊 Salish Sea Watershed

Interactive Geospatial Visualization of Puget Sound and Georgia Strait

About This Project

This interactive mapping project visualizes the Salish Sea watershed, including Puget Sound, the Georgia Strait, and the surrounding rivers, streams, mountains, and forests. The Salish Sea is a complex inland sea system in the Pacific Northwest, bordered by Washington State and British Columbia.

The maps show the drainage basin with colored features for the main region and greyed-out surrounding areas for context. All data comes from open-source public datasets.

Technical Details

Data Sources

  • Natural Earth Data: Global physical features (coastlines, rivers, lakes, populated places)
  • OpenStreetMap: Detailed waterways, forests, and mountain peaks
  • USGS NHD: Referenced for watershed boundaries (manual download)
  • Elevation: 3D terrain uses synthetic elevation for demonstration (real SRTM integration planned)

Technologies Used

  • Python: Data processing and map generation
  • GeoPandas: Geospatial data manipulation
  • Folium: Interactive 2D web mapping
  • Plotly: 3D terrain visualization
  • GitHub Pages: Free static site hosting

Project Structure

How to Use This Project

  1. Clone the repository: git clone https://github.com/AhutGupta/puget-sound-drainage.git
  2. Install dependencies: pip install -r requirements.txt
  3. Download data: python src/download_data.py
  4. Process data: python src/process_data.py
  5. Generate maps: python src/visualize_2d.py python src/visualize_3d.py
